# fdm-design-skill

Repository for the `fdm-design` Claude Code skill. Read `AGENTS.md` before editing.

- The skill is `skills/fdm-design/SKILL.md` (under 200 lines); numbers live in
  `skills/fdm-design/references/` with sources; checks live in `skills/fdm-design/scripts/`.
- Before finishing any change run `python scripts/validate.py` and `python -m pytest -q tests`.
- Never add personal data or absolute local paths; never copy text or code from non-permissive
  sources.
